# Security Policy

## Supported versions

Security fixes are made against the latest code on the `main` branch. Prototype
releases are for testing and may contain defects; update to the latest
available build when investigating a possible security issue.

## Reporting a vulnerability

Please do not report vulnerabilities in public issues or pull requests.

Use GitHub's **Report a vulnerability** option on the repository's Security
tab to send a private report. If private vulnerability reporting is not
available, contact a repository maintainer privately through their GitHub
profile and ask for a secure reporting channel before sending sensitive
details.

Include the affected version or commit, the Android version and device if
relevant, the steps needed to reproduce the issue, and its potential impact.
Do not attach recordings containing personal or sensitive information.

Maintainers will acknowledge reports as soon as practical, investigate them,
and coordinate any fix and disclosure with the reporter. Please allow time for
a fix before sharing vulnerability details publicly.
